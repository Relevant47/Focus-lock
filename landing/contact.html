Response time

FocusLock is built by one person, so replies usually take 1–3 days. If your message is urgent and you don't hear back in a week, send a quick nudge — it occasionally gets caught in a filter.

Prefer GitHub?

Bug reports and feature requests are also welcome on GitHub Issues. Public issues help other users find solutions.

Security disclosures

Found a security issue? Please email hello@tryfocuslock.com with "security" in the subject line rather than opening a public GitHub issue, so we can patch before disclosure.
