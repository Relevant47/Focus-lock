Privacy Policy

Last updated: May 24, 2026

Short version: The core FocusLock app collects nothing — no account, no telemetry, no analytics, no payment data. Everything stays on your device. The one exception is the optional Family Controls feature: if you use it, you create an account and a small amount of data about each paired device is stored on our family-controls server so a parent can manage a child's device. If you never use Family Controls, none of that applies.

1. What the core app collects

Used on its own, FocusLock collects no personal data whatsoever. All application data — your focus profiles, session history, block lists, analytics, and settings — is stored locally on your device in:

  • Windows: %ProgramData%\FocusLock\
  • macOS: /Library/Application Support/FocusLock/

This data never leaves your device. There is no account, no sign-in, and nothing is uploaded.

2. Software updates

FocusLock periodically checks for updates by contacting our update server and the GitHub API. This request includes:

  • Your operating system and CPU architecture (e.g. "windows-x86_64")
  • Your current FocusLock version number

No personally identifiable information is included. Your IP address is visible to the update server as part of the normal HTTP request, but it is not logged or stored.

3. No telemetry

FocusLock has no crash reporting, telemetry, analytics, or tracking of any kind. We receive no data about how you use the application, which sites you block, or how long your sessions are. The full source code is public on GitHub — you can verify this yourself.

4. Family Controls (optional)

Family Controls is an opt-in feature that lets a parent on one device block apps and websites on a child's device. To make this work, the two devices coordinate through a hosted server (the "family server"). This is the only part of FocusLock that stores any data off your device, and it is only used if you choose to use Family Controls. If you never sign up for or pair a device with Family Controls, nothing here applies and no account or server is involved.

When you use Family Controls, the family server stores:

  • Account information — the parent's email address and a securely hashed password (the password itself is never stored in plain text).
  • Paired-device information — for each child device you pair: its hostname/computer name, operating system and version, the dates it was paired and last seen, and the IP address it most recently connected from.
  • Block rules — the apps, website domains, and schedules a parent has chosen to enforce on a device.
  • An activity log — a record of family-controls events (such as a device being paired or unpaired, a block being applied, sign-in attempts, and tamper or offline alerts), including the IP address and time of each event.

What the family server does not store: your browsing history, the contents of your screen, keystrokes, or which specific sites a child actually visited. FocusLock records what was blocked, never what was viewed — it is a blocking tool, not surveillance.

This data is stored on Cloudflare infrastructure (the family server runs on Cloudflare Workers and D1). You can export everything tied to your account as JSON or permanently delete your account (which cascades to all paired devices, rules, and activity history) from the Family tab in the app at any time. The family server is itself open-source and part of the public repository, so you can audit exactly what it stores — or run your own server instead of ours.

5. No account required for the core app

Downloading and using FocusLock as a personal distraction blocker does not require an account, email address, or any personal information. There is no registration process. An account is only created if you choose to use Family Controls (see section 4).

6. No payments

FocusLock is completely free. We do not process payments and we do not collect any financial information. (The hosted Family Controls server may become a paid option in the future; if that happens, this policy will be updated to describe any payment processing.)

7. Children's privacy

The core FocusLock app does not collect information from anyone, including children. Family Controls is designed for a parent or guardian to manage a child's device, and the limited device information described in section 4 (hostname, OS, last-seen time, IP address, and which apps/sites are blocked) is collected only when a parent sets up and uses that feature. We do not collect browsing history, message contents, or other personal details about a child. A parent or guardian who sets up Family Controls is responsible for any consent required for managing their child's device.

8. Changes to this policy

If we make material changes to this policy, we will update the "Last updated" date above. Changes will also be reflected in the GitHub repository.
